# Examples

Every document this library makes, as a PDF you can open before installing anything.

Generated by the library itself — `WRITE_EXAMPLES=1 swift test --filter ExampleTests` — so none of them can drift from what the code actually produces. Each one is checked as it is written: it must be a readable PDF, and every tax document must pass `complianceWarnings(verifying:)`, which reads the finished page rather than the model.

## VAT treatments

Where VAT is not charged at the domestic rate, the wording *is* the document — an invoice missing it can be refused as evidence for the recipient's input-tax deduction.

- [reverse-charge](invoices/vat-reverse-charge.pdf) — Article 196, in English and German
- [intra-community](invoices/vat-intra-community.pdf) — Article 138
- [export](invoices/vat-export.pdf) — outside the scope
- [small-business](invoices/vat-small-business.pdf) — §19 UStG
